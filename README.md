# 🚨 Complaint Management and Rescue System

A Java-based console application designed to manage citizen complaints and emergency rescue requests efficiently. The system provides separate functionalities for users and administrators, allowing complaints to be registered, tracked, managed, and exported while supporting emergency assistance for police, fire, medical, and natural-disaster situations.

---

## 📌 Project Overview

The Complaint Management and Rescue System provides a centralized platform for handling citizen complaints and emergency assistance requests.

Users can create an account, log in, register complaints, check complaint information, and request emergency assistance. Administrators can manage workers, view and filter complaints, and generate complaint reports.

The application uses **Java** for the application logic and **MySQL** for persistent data storage through **JDBC**.

---

## ✨ Features

### 👤 User Features

- User registration
- User login and logout
- Profile management
- Complaint registration
- Complaint lookup
- Complaint information management
- Emergency assistance guidance

### 🚨 Emergency Rescue

The system provides emergency assistance options for:

- 👮 Police
- 🚒 Fire Brigade
- 🚑 Medical / Ambulance
- 🌪️ Natural Disasters

### 👨‍💼 Admin Features

- Admin authentication
- Admin dashboard
- Worker management
- View complaints
- Filter complaints
- Manage complaint information
- Export complaint reports
- Department-based complaint reports
- Date-range complaint reports
